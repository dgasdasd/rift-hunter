# 裂隙猎场 · RIFT HUNTER

第三人称高位跟随视角的单人 3D 动作 Roguelite。使用 Three.js 和 Vite，模型、场景、动作、材质和音效均由本项目程序生成。

## 运行

双击游戏目录的 `启动游戏.cmd`（也可使用练习目录的启动脚本），或：

```powershell
npm install
npm run build
npm run preview -- --strictPort
```

打开 http://127.0.0.1:5178/ 。开发模式为 `npm run dev`。运行环境 Node.js 22+，浏览器须支持 WebGL。构建后的游戏不请求外部模型、图片、字体或音频；进度保存在当前浏览器的 localStorage。

### 手机访问

手机与电脑连接同一 Wi-Fi，电脑保持游戏预览运行。手机浏览器打开 `http://电脑的无线局域网IPv4地址:5178/`，例如 `http://192.168.1.100:5178/`。电脑地址可通过 PowerShell 的 `Get-NetIPConfiguration` 或 `ipconfig` 查看，重新连接网络后可能变化。

正式预览和启动脚本监听 `0.0.0.0`，支持局域网访问。手机建议横屏，使用摇杆和动作按钮；性能不足时切换到“流畅”画质。电脑与手机的浏览器存档分别保存。

若手机打不开，检查电脑防火墙是否允许 TCP 5178，以及 Wi-Fi 是否启用了访客隔离/设备隔离。可以让手机与电脑都连接同一个手机热点再尝试。

### GitHub Pages

在线游玩：https://dgasdasd.github.io/rift-hunter/ 。手机可使用流量或任意 Wi-Fi，无需电脑开机。推荐横屏游玩。

本项目已配置相对资源路径和 `.github/workflows/pages.yml`。将代码推送到 GitHub 仓库的 `main` 分支，并将 Settings → Pages → Source 设为 GitHub Actions，工作流会运行测试、构建并发布游戏。公开网页可使用手机流量或任意网络访问，不需要保持本机运行。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 普通攻击 | 鼠标左键 / J，可长按 |
| 重击 | 鼠标右键 / K，消耗耐力 |
| 闪避 | Space，有短暂无敌时间 |

| 暂停 / 路线 | Esc / Tab |

默认辅助瞄准在鼠标停止移动后选取最近的敌人。触屏使用摇杆和动作按钮，推荐横屏。暂停菜单可查看完整铭文构筑。画面有流畅、均衡、精细三个档位。

## 内容

- 三种武器：三段连击长剑、破防重锤、远程能量弩；各有重击与专属技能。
- 独立肩、肘、握持关节与腰部动作。长剑三连击分别为横斩、反向横斩、下劈；重击和回旋技能使用专属动作，刀光跟随实际武器运动。
- 六种普通敌人：追击、远程、盾兵、冲锋、范围施法、治疗辅助。精英变体有额外生命与奖励。
- 十段分岔远征路线、十四种房间布置。普通战斗有 2–3 波守卫，精英房间 3 波，每波 3–6 名守卫。
- 第五段磐石守门者、第十段裂隙之主；各有两阶段、不同攻击序列、冲锋/弹幕/范围攻击。
- 三十种铭文，包括毒素、连锁雷电、击杀爆炸、闪避冲击、护身星环等真实行为变化。
- 商店、治疗圣所、生命献祭、诅咒宝箱、可攻击的爆炸桶。
- 当前局自动保存、胜败结算、最好成绩、星砂收藏、试炼难度。累计 50 星砂解锁角色翡翠徽记和披风。

不是无缝开放世界；房间之间通过星门选择路线。不同玩家和构筑的通关时间会不同，自动策略测试的模拟时间不能当作真人游戏时长。

## 数值与节奏

初始生命 100、耐力 100，携带 2 瓶药水。药水基础恢复 35 生命，上限 4 瓶。前期轻型敌人通常需要一套长剑连击；后期普通守卫生命每段提高 6%，伤害每段提高 2.5%。

| 武器 | 普攻伤害 / 间隔 | 重击伤害 / 耐力 | 技能伤害 / 冷却 / 耐力 |
| --- | --- | --- | --- |
| 长剑 | 18 / 0.44 秒 | 44 / 22 | 56 / 8 秒 / 28 |
| 重锤 | 32 / 0.78 秒 | 76 / 28 | 80 / 9 秒 / 34 |
| 能量弩 | 15 / 0.42 秒 | 38 / 20 | 每箭 30，同一目标最多 2 箭 / 8 秒 / 26 |

磐石守门者 950 生命，裂隙之主 1450 生命；Boss 不重复乘普通守卫的关卡生命加成。试炼模式敌人生命、伤害提高 20%。

伤害铭文加成相加，吸血按实际扣除敌人的生命计算，暴击为 1.75 倍。功能已完整解锁的铭文不再重复出现，数值铭文通常最多三层，具体限制见说明。

商店铭文 65、治疗 25、药水 35 金币；治疗恢复 35 生命，每件商品各限一次。闪避消耗 24 耐力；耐力每秒恢复 18，攻击时按 60% 回复，闪避期间暂停回复。

旧存档自动转换至新版数值，保留路线、金币、收藏以及生命百分比；不需要删除存档。更完整的调整理由和验证结果见 `balance-notes.md`。

## 验证与维护

`npm test` 检查碰撞、攻击、敌人导航、铭文、存档、波次和胜败等核心逻辑。浏览器测试脚本在 `artifacts/`，使用本机已有 Playwright / Chrome，详见 `validation-report.md`。

`?test=1` 是仅供测试的驱动接口；正常地址仅提供只读运行快照。不要将测试驱动用于展示玩家成绩。

## 文件

- `src/simulation.js`：权威游戏状态、120Hz 更新、碰撞与玩法。
- `src/data.js`：武器、敌人、铭文、房间配置。
- `src/world.js`：模型、灯光、阴影、镜头、渲染插值和特效。
- `src/attack-animation.js`：武器动作关键帧、转腰、连击与收势。
- `src/main.js`：输入、菜单、HUD、存档和状态流程。
- `src/audio.js`：Web Audio 合成的战斗音效与氛围音符。

Three.js 和 Vite 按各自许可证使用。未引入外部美术或音乐资产。
